# Changelog

## 0.2.0

Implemented account verification/recovery/MFA and OIDC identity linking; organization membership/policies/library/audit administration; account-owned projects and hosted prototype snapshots; character-level collaborative rich text with range formats and local-intent undo; Bézier editing and worker-backed Boolean operations; a compressed/encrypted SQLite operation journal, local multi-process catch-up, retry receipts and verified backup/restore; safe SVG/ZIP and documented-design adapters; server-allowlisted image/text model jobs, cancellation, history, encrypted overrides and budgets.

Added format/semantic validation, rounded/transformed GPU clips, mixed-style Canvas/SVG/HTML export, nonce CSP, additional quotas, concurrency/crash tests and UI acceptance suites. Fixed vector-toolbar pointer routing, portable import remapping, rich-text checkpoint restoration, first-resize path coordinate baselines and invitations opened in an already-running editor.

Full private binary compatibility, independent security certification and live external model/tenant verification are not implied by this release.

## 0.1.0

Initial plain HTML/JS editor, hybrid WebGPU renderer, multi-screen design/prototypes, local persistence and capability-based collaboration.
