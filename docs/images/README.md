# Editor screenshots

`editor-preview.png` is captured from the actual static release by the Pages acceptance test during repository import. To regenerate it, run `npm run build`, `python tests/pages_test.py`, then copy `test-artifacts/pages-editor.png` here as `editor-preview.png`.

The original 0.2.0 source archive includes the full-resolution historical screenshots. Other browser suites create their screenshots in `test-artifacts/`.
