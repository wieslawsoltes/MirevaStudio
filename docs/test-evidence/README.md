# Executed test evidence — 0.2.0

See ../TESTING.md for environment, scope and reproducible commands. All files here are actual test results except `recovery.json`, which transcribes and sanitizes the executed administrative commands' JSON output. `build-and-node.log` is the complete latest syntax, Node test and build log. The example room/node identifiers in reports are temporary test objects, not access tokens.

The acceptance harnesses create isolated test accounts. Their private outboxes, passwords, sessions, databases and encryption keys are not part of this release. Screenshots in ../images are actual application captures using synthetic designs and identities.

Full-resolution screenshots are included in the original 0.2.0 delivery archive. The repository retains a compressed editor preview; browser suites regenerate full-size images under `test-artifacts/`.
